# Security Policy

## Supported Versions

This repository is currently maintained for the latest main branch.

## Reporting a Vulnerability

Please report security issues privately by emailing the maintainer at pawankumarkharpue@gmail.com

Do not open public issues for security vulnerabilities.

## Security Expectations

- Never commit secrets or credentials.
- Use environment variables for configuration.
- Keep dependencies up to date.
- Review logs and screenshots before publishing artifacts.
