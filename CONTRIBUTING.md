# Contributing

Thank you for helping improve this framework.

## Principles

- Keep the framework maintainable and production-focused.
- Prefer reusable abstractions over duplication.
- Avoid hardcoded secrets and brittle selectors.
- Follow the existing page-object and fixture patterns.

## Workflow

1. Create a branch from main.
2. Implement your change with tests where appropriate.
3. Run the relevant Playwright suite.
4. Submit a pull request with a clear summary.
